# 跨境电商与外贸实用资源清单

面向跨境电商卖家、外贸业务员、独立站运营和出海团队，整理能用于学习、查规则和处理日常业务的官方资源。

由 [TOOLBBS](https://www.toolbbs.com/) 整理与维护。

**首版：30 项官方资源，六类各 5 项；附 4 篇已核验的中文教程，作为对应资源的补充阅读，不重复计入资源数量。**

**本次检查日期：2026-10-10（America/Chicago）。** 收录前已逐项访问官方页面并检查正文；链接访问结果、重定向和检查限制见 [链接核验记录](docs/LINK_CHECK.md)。

## 如何使用

- 先按业务问题选分类，再阅读资源的用途、适用人群和限制。
- “公开阅读”只说明本次能查看资料，不代表开店、软件、物流或收款服务免费。
- 未能确认的价格、额度和资格明确标为“本次未确认”；本文不提供跨地区通用报价。
- 中文教程帮助理解操作流程。套餐、平台规则、许可证、税务与清关要求以相应官方资料为准；教程中的历史价格不作为本清单报价。
- 这是一份资料清单。本次未执行真实开店、付款、发货、清关或税务申报。

## 平台官方资源

### 01. [Amazon Seller University](https://sell.amazon.com/learn/seller-university)

- **用途：** 学习商品发布、定价、订单配送、广告和卖家账户运营。
- **适用人群：** 准备进入亚马逊的新卖家，以及需要补齐运营知识的团队。
- **费用与限制：** 官方明确为免费教育资源，未开店者也可学习。开店、销售佣金、FBA 和广告成本另计；规则需按实际销售站点核对。

### 02. [eBay Seller Center](https://www.ebay.com/sellercenter)

- **用途：** 查阅刊登、商品信息、退货、国际销售、卖家保护和费用说明。
- **适用人群：** eBay 卖家、店铺运营和售后人员。
- **费用与限制：** 公开资料可阅读；店铺、刊登、成交和广告的实际费用本次未逐地区确认。链接为美国站，其他站点规则可能不同。

### 03. [Alibaba.com Seller Central](https://seller.alibaba.com/)

- **用途：** 了解 B2B 卖家入驻、店铺展示和线上获客，寻找官方销售与学习入口。
- **适用人群：** 工厂、批发商、OEM/ODM 供应商及外贸业务团队。
- **费用与限制：** 入口可公开浏览；会员、广告、增值服务及中国卖家具体报价本次未确认。主体、地区和行业资格需向官方核实。
- **中文补充（TOOLBBS）：** [阿里巴巴国际站入驻与 B2B 运营指南](https://www.toolbbs.com/sites/1454.html)——可参考产品资料、RFQ 筛选、询盘回复和报价准备步骤；费用与入驻要求仍需回到官方确认。

### 04. [Walmart Marketplace Learn](https://marketplacelearn.walmart.com/)

- **用途：** 查阅商品设置、订单管理、退货、回款、WFS 和卖家培训资料。
- **适用人群：** 准备或已经经营 Walmart Marketplace 的品牌与运营团队。
- **费用与限制：** 已核验公开学习页面；论坛等功能需要登录，完整功能依赖 JavaScript。市场准入、销售和履约费用本次未确认。

### 05. [Etsy Seller Handbook](https://www.etsy.com/seller-handbook)

- **用途：** 学习开店、商品展示、品牌经营、搜索优化和客户服务。
- **适用人群：** 手工艺、设计、复古商品及符合 Etsy 商品规则的卖家。
- **费用与限制：** 手册可公开阅读；开店、刊登、支付及广告费用本次未确认。开店地区、身份审核和商品资格需单独检查。

- **用途：** 通过官方课程学习站点搭建、区块编辑、设计和开发基础。
- **适用人群：** 外贸企业官网维护者、内容运营、新站站长和 WordPress 初学者。
- **费用与限制：** 官方明确提供免费学习资源；部分学习进度或互动功能需账号。购买主机、域名和商业插件的费用本次未确认。

### 09. [Cloudflare 基础文档](https://developers.cloudflare.com/fundamentals/)

- **用途：** 学习账户、域名接入和基础网络服务，为独立站的 DNS、安全和访问性能配置提供官方依据。
- **适用人群：** 独立站负责人，以及负责域名与网站运维的人员。
- **费用与限制：** 文档可公开阅读；产品与套餐分别计费，具体价格和可用额度以 [官方价格页](https://www.cloudflare.com/plans/) 为准。修改 DNS 前应核对原站点配置。

### 10. [PageSpeed Insights](https://pagespeed.web.dev/)

- **用途：** 检查网站移动端与桌面端性能，查看 Core Web Vitals 和页面优化线索。
- **适用人群：** 独立站运营、SEO 人员和网站维护团队。
- **费用与限制：** 本次可直接打开检测入口；批量 API 配额本次未确认。实测用户数据可能不足，实验室测试不能替代真实用户体验；见 [官方说明](https://developers.google.com/speed/docs/insights/v5/about)。

## 物流与清关

### 16. [DHL 商业发票填写指南](https://www.dhl.com/discover/en-us/global-logistics-advice/essential-guides/how-to-prepare-a-commercial-invoice)

- **用途：** 核对商业发票中的交易双方、商品描述、价值、原产地及运输相关信息。
- **适用人群：** 跨境发货人员、外贸跟单和准备出口单证的卖家。
- **费用与限制：** 指南可公开阅读；运输、税费及报关服务费用本次未确认。页面属于美国地区指南，具体文件要求应按出发地、目的地和货物核对。

### 17. [UPS 国际运输单证指南](https://www.ups.com/us/en/support/international-tools-resources/international-forms-certificates)

- **用途：** 了解商业发票、原产地资料及出口信息文件的用途，检查国际包裹所需单证。
- **适用人群：** 使用 UPS 的出口团队、物流人员和订单履约人员。
- **费用与限制：** 指南可公开阅读；电子发票等功能可能要求 UPS 账户。运费、代理服务及关税本次未确认，美国出口表单不能直接套用到所有国家。

### 18. [FedEx 清关文件指南](https://www.fedex.com/en-us/shipping/international/create-documents.html)

- **用途：** 查阅商业发票、原产地证明和其他清关资料，并找到官方文件准备工具。
- **适用人群：** 使用 FedEx 的卖家、发货人员和外贸单证人员。
- **费用与限制：** 指南可公开阅读；运输工具的账户和地区适用性需核实，实际物流费用本次未确认。所需文件取决于货物和贸易路线。

### 19. [欧盟 Access2Markets](https://trade.ec.europa.eu/access-to-markets/en/home)

- **用途：** 按商品与贸易路线查询关税、原产地、手续和市场准入信息。
- **适用人群：** 评估欧盟市场的出口企业、外贸业务和合规人员。
- **费用与限制：** 已核验欧盟官方公共入口；查询需提供正确的商品编码、原产国和目的地。本文未确认任何具体商品的税率或准入结论。

### 20. [英国 EORI 官方指南](https://www.gov.uk/eori)

- **用途：** 了解涉及英国货物流转时何种情况需要 EORI，以及相关申请入口。
- **适用人群：** 向英国销售、在英国备货或安排英国进口的企业与物流人员。
- **费用与限制：** 官方指南可公开阅读；大不列颠、北爱尔兰及欧盟的适用范围应分别核对。本次未核验某个企业的申请资格、办理时长或代理收费。

## 收款与税务

### 26. [PayPal 商家服务](https://www.paypal.com/c2/business)

- **用途：** 了解独立站收款、付款与商家解决方案，检查收款产品和费用信息。
- **适用人群：** 使用 PayPal 收款的独立站卖家、外贸企业和财务人员。
- **费用与限制：** 商业收款、兑换等可能收费，见 [中国大陆相关商家费率说明](https://www.paypal.com/c2/business/paypal-business-fees)。不同开户协议、账户地区和产品适用费用不同；本次未确认某一商家的最终费率或结算条件。

### 27. [Stripe 支持地区](https://stripe.com/global)

- **用途：** 在接入信用卡与其他在线支付前，先检查商家注册地是否属于 Stripe 支持范围。
- **适用人群：** 独立站负责人、海外企业和计划接入 Stripe 的技术与财务团队。
- **费用与限制：** 官方地区页面可公开阅读；支持商家所在地与买家能付款是不同问题。开户审核、行业限制、交易费率与提现条件本次未针对具体主体确认；页面可能按地区重定向。

### 28. [Wise Business](https://wise.com/business/)

- **用途：** 了解企业多币种账户、跨境转账和收付款能力，评估外贸结算工具。
- **适用人群：** 需要多币种业务的外贸企业、海外公司和财务团队。
- **费用与限制：** 账户和功能按企业注册地、业务类型等区分，先阅读 [企业适用性说明](https://wise.com/help/articles/2977974/can-my-business-use-wise)。具体开户、兑换、转账费用及某一企业是否获批本次未确认；不应视为所有中国企业均可开通。

### 29. [欧盟 VAT One Stop Shop](https://vat-one-stop-shop.ec.europa.eu/index_en)

- **用途：** 查阅欧盟电商 VAT 的 OSS/IOSS 官方说明、制度范围和相关资料。
- **适用人群：** 面向欧盟消费者销售的跨境卖家、税务与合规人员。
